Personal-AI-Memory

English 简体中文

Personal-AI-Memory is a personal tool that exports your own Google Docs to Markdown on your own computer.

It is a single-user desktop tool by GitHub user ganghuxie. It is not a hosted service. On the owner’s Windows PC, rclone uses the desktop OAuth client named PAM-rclone to sign in to the owner’s own Google account and access that account’s Google Drive.

What it is for

The requested OAuth scope is https://www.googleapis.com/auth/drive. Personal-AI-Memory uses that access to export Google Docs as Markdown into a local staging folder. Those files can later be archived into the owner’s local Obsidian notes vault.

Google describes this scope as permission to see, edit, create, and delete all files in the Google Drive of the account that grants access. The purpose of this client is the local export above. rclone runs only on the computer where you start it, and you control which commands it runs.

Your files stay on your computer

Exporting and archiving happen locally. Personal-AI-Memory does not send Google Drive files, document contents, or OAuth tokens to the developer or to any third-party server. Data is not sold, shared, used for advertising, or used to train AI models.

OAuth tokens are stored only in the local rclone configuration file. You can revoke access at any time from your Google Account permissions.

Read the Privacy Policy. It explains which Google user data is accessed, how it is used and stored, that it is not shared, how long it is kept, and how to revoke access.

Contact

Questions and requests go through GitHub issues: https://github.com/ganghuxie/ganghuxie.github.io/issues

简体中文

Personal-AI-Memory 是一个个人工具，用来在你自己的电脑上，把你自己的 Google 文档导出为 Markdown。

它是 GitHub 用户 ganghuxie 的单用户桌面工具，不是托管服务。在所有者的 Windows 电脑上，rclone 使用名为 PAM-rclone 的桌面 OAuth 客户端，登录所有者自己的 Google 账号，并访问该账号的 Google 云端硬盘（Google Drive）。

用途

所请求的 OAuth 权限范围是 https://www.googleapis.com/auth/drive。Personal-AI-Memory 使用该授权，将 Google 文档（Google Docs）导出为 Markdown，保存到本机暂存文件夹。之后可以把这些文件归档到所有者本机的 Obsidian 笔记库。

Google 对该权限范围的说明是：可以查看、编辑、创建和删除授权账号的 Google 云端硬盘中的全部文件。此客户端的用途是上面所说的本地导出。rclone 只在你启动它的那台电脑上运行，执行哪些命令由你自己决定。

文件留在你的电脑上

导出和归档都在本地完成。Personal-AI-Memory 不会把 Google 云端硬盘中的文件、文档内容或 OAuth 令牌发送给开发者或任何第三方服务器。数据不会被出售、分享或用于广告，也不会用于训练人工智能模型。

OAuth 令牌只保存在本机的 rclone 配置文件中。你可以随时在 Google 账号权限页面撤销访问。

请阅读隐私政策。其中说明本应用会访问哪些 Google 用户数据、如何使用和存储、不会分享这些数据、保留多久，以及如何撤销访问。
