Privacy Policy

Personal-AI-Memory · Effective date: 2026-10-27

English 简体中文

This policy describes how Personal-AI-Memory accesses, uses, stores, and shares Google user data. The Google OAuth application name is Personal-AI-Memory. The desktop OAuth client is named PAM-rclone. The application is a personal, single-user desktop tool published by GitHub user ganghuxie. Its home page is https://ganghuxie.github.io/.

The application

Personal-AI-Memory is intended for its owner to use on the owner’s own Windows computer, with the owner’s own Google Drive. rclone, running on that computer, uses the PAM-rclone desktop OAuth client to export Google Docs as Markdown into a local staging folder. The owner can later archive those files into a local Obsidian notes vault.

There is no Personal-AI-Memory account server. Authorizing the application does not create an account with the developer. If you authorize it, the Google data described below is handled on the computer where you run rclone.

Google user data that is accessed

When a Google account is connected, Personal-AI-Memory requests this OAuth scope:

https://www.googleapis.com/auth/drive

Google describes that scope as permission to see, edit, create, and delete all of your Google Drive files. With it, the application can view file metadata and file contents in the Google Drive of the account that grants access, and can download those files. The intended use is to find Google Docs and export them as Markdown.

Google also issues OAuth credentials for that connection, including an access token and a refresh token, so rclone can continue to call the Drive API from your computer.

Personal-AI-Memory does not request Gmail, Google Calendar, Google Contacts, or other Google products. It does not ask you to type a Google password into the application. Sign-in is Google’s own OAuth screen.

How Google user data is used

Google user data is used only to provide the local export you run yourself:

  • Find Google Docs in your Google Drive.
  • Export those documents as Markdown.
  • Save the exported files in a staging folder on your computer.
  • Allow you to archive those files into your local Obsidian notes vault.

The application does not use Google user data for advertising. It does not sell Google user data. It does not use Google user data, or data derived from it, to train artificial intelligence or machine learning models. It does not build advertising profiles from Google user data.

The granted Drive scope is broader than read-only export. rclone can use the token for the Drive commands you choose to run on your computer. Personal-AI-Memory does not operate a service that edits or deletes Drive files on its own.

How Google user data is stored

Processing stays on your computer.

  • Exported Markdown, and any Drive file contents rclone downloads, are stored only on your computer. That means the local staging folder and, if you copy them there, your local Obsidian vault.
  • OAuth tokens are stored only in the local rclone configuration file on that computer.
  • Personal-AI-Memory does not upload Google user data to the developer.
  • Personal-AI-Memory does not send Google user data to a third-party server.
  • The developer does not keep a copy of your Drive files, document contents, or OAuth tokens.

How Google user data is shared

Google user data is not shared.

  • It is not shared with the developer.
  • It is not shared with third parties.
  • It is not sold, rented, or traded.
  • It is not used for advertising or marketing.
  • It is not sent to an analytics service, advertising network, or AI training service.

The developer does not receive your Google user data and therefore has nothing to transfer. Only the person at the computer where rclone is running handles the exported files. No one else is given access to those files through this application.

Limited Use

Personal-AI-Memory’s use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

For this application, that means:

  • Google user data is used only to provide the local Google Docs export described on the Personal-AI-Memory home page.
  • Google user data is not transferred to the developer or to others. Files move only if you yourself copy them on your own computer.
  • Google user data is not used to serve advertisements.
  • The developer does not read your Google user data. Humans other than you are not given access to it through this application.

Retention and deletion

  • Exported files remain on your computer until you delete them. Delete the staging folder, and delete any copies you archived in your Obsidian vault, when you no longer want them.
  • OAuth tokens remain in the local rclone configuration file until you remove that rclone remote or delete the configuration file.
  • Revoking access in your Google Account stops further access. It does not erase Markdown files already saved on your computer. Delete those local files yourself if you want them gone.
  • The developer has no server copy of your Google user data to retain or to delete. A deletion request cannot return or erase a copy the developer never received. Local deletion is done by you, on your computer.

How to revoke access

You can remove Personal-AI-Memory’s access to your Google Account at any time:

  1. Open https://myaccount.google.com/permissions.
  2. Find Personal-AI-Memory in the list of apps with access to your account. The desktop client name PAM-rclone may also be shown.
  3. Remove access, or delete all connections you have with that app.

You can also stop local use by removing the rclone remote or by deleting the local rclone configuration that holds the tokens.

This website

ganghuxie.github.io is a static site. It does not run analytics, does not use tracking scripts, does not set cookies, and has no forms. Visiting the home page or this privacy policy does not send personal information to the developer.

Contact

Contact the developer by opening a GitHub issue: https://github.com/ganghuxie/ganghuxie.github.io/issues

Do not include OAuth tokens, rclone configuration, passwords, or private document contents in an issue.

关于本应用

Personal-AI-Memory 供其所有者在自己的 Windows 电脑上使用，访问所有者自己的 Google 云端硬盘。运行在该电脑上的 rclone 使用 PAM-rclone 桌面 OAuth 客户端，将 Google 文档导出为 Markdown，保存到本机暂存文件夹。所有者之后可以把这些文件归档到本机的 Obsidian 笔记库。

Personal-AI-Memory 没有账号服务器。授权此应用不会在开发者处创建账号。如果你授权它，下面所述的 Google 数据只在你运行 rclone 的那台电脑上处理。

访问的 Google 用户数据

连接 Google 账号时，Personal-AI-Memory 请求以下 OAuth 权限范围：

https://www.googleapis.com/auth/drive

Google 对该权限范围的说明是：可以查看、编辑、创建和删除你的全部 Google 云端硬盘文件。据此，本应用可以查看授权账号的云端硬盘文件元数据和文件内容，并可以下载这些文件。预期用途是找到 Google 文档并将其导出为 Markdown。

Google 还会为该连接签发 OAuth 凭证，包括访问令牌和刷新令牌，以便 rclone 从你的电脑继续调用 Drive API。

Personal-AI-Memory 不请求 Gmail、Google 日历、Google 通讯录或其他 Google 产品。它不会要求你在应用中输入 Google 密码。登录使用的是 Google 自己的 OAuth 页面。

如何使用 Google 用户数据

Google 用户数据只用于提供由你在本地运行的导出功能：

  • 在你的 Google 云端硬盘中查找 Google 文档。
  • 将这些文档导出为 Markdown。
  • 把导出的文件保存到你电脑上的暂存文件夹。
  • 由你自行把这些文件归档到本机的 Obsidian 笔记库。

本应用不会将 Google 用户数据用于广告，不会出售 Google 用户数据，也不会把 Google 用户数据或其衍生数据用于训练人工智能或机器学习模型，不会用 Google 用户数据建立广告画像。

所授予的 Drive 权限范围宽于只读导出。rclone 可以把该令牌用于你在自己电脑上选择运行的 Drive 命令。Personal-AI-Memory 没有会自行编辑或删除云端硬盘文件的在线服务。

如何存储 Google 用户数据

处理过程留在你的电脑上。

  • 导出的 Markdown，以及 rclone 下载的云端硬盘文件内容，只保存在你的电脑上。也就是本机暂存文件夹，以及你若自行复制过去的本机 Obsidian 笔记库。
  • OAuth 令牌只保存在该电脑的 rclone 本地配置文件中。
  • Personal-AI-Memory 不会把 Google 用户数据上传给开发者。
  • Personal-AI-Memory 不会把 Google 用户数据发送到第三方服务器。
  • 开发者不会保留你的云端硬盘文件、文档内容或 OAuth 令牌的副本。

如何分享 Google 用户数据

Google 用户数据不会被分享。

  • 不会与开发者分享。
  • 不会与第三方分享。
  • 不会被出售、出租或交换。
  • 不会用于广告或营销。
  • 不会发送给分析服务、广告网络或人工智能训练服务。

开发者不会收到你的 Google 用户数据，因此也没有可转移的内容。只有在运行 rclone 的那台电脑前的使用者会接触导出的文件。本应用不会把这些文件的访问权交给其他人。

有限使用（Limited Use）

Personal-AI-Memory 对从 Google API 接收的信息的使用，遵守 Google API 服务用户数据政策（Google API Services User Data Policy），包括有限使用（Limited Use）要求。

对本应用而言，这意味着：

  • Google 用户数据只用于提供 Personal-AI-Memory 主页所述的本地 Google 文档导出功能。
  • Google 用户数据不会转移给开发者或其他人。文件只会在你自己于自己的电脑上复制时移动。
  • Google 用户数据不会用于投放广告。
  • 开发者不会阅读你的 Google 用户数据。本应用不会把该数据的访问权交给你以外的人。

保留与删除

  • 导出的文件会留在你的电脑上，直到你删除它们。不再需要时，请删除暂存文件夹，并删除你归档到 Obsidian 笔记库中的副本。
  • OAuth 令牌会留在 rclone 本地配置文件中，直到你移除该 rclone remote，或删除该配置文件。
  • 在 Google 账号中撤销访问后，后续访问会停止。这不会抹去已经保存在你电脑上的 Markdown 文件。如果你希望这些本地文件消失，请自行删除。
  • 开发者没有你的 Google 用户数据的服务器副本可供保留或删除。删除请求无法交回或擦除开发者从未收到的副本。本地删除由你在自己的电脑上完成。

如何撤销访问

你可以随时移除 Personal-AI-Memory 对你的 Google 账号的访问权限：

  1. 打开 https://myaccount.google.com/permissions。
  2. 在有权访问你账号的应用列表中找到 Personal-AI-Memory。桌面客户端名称 PAM-rclone 也可能一并显示。
  3. 移除访问权限，或删除你与该应用的全部连接。

你也可以通过移除 rclone remote，或删除保存令牌的 rclone 本地配置，来停止本地使用。
